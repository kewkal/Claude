# Running these organically on Instagram & Facebook

The Hook Archetype SOP was built from viral **TikTok Shop** ads. The hook mechanics carry over to Reels unchanged.
A few things are different on Instagram and Facebook. This file covers those differences. Where it conflicts with the SOP on
*platform mechanics*, this file wins. On *hook structure and kill gate*, the SOP always wins.

## What stays the same
- 30–40s runtime, universal skeleton, audio switch, two-person physical hook, old way failing in frame.
- Kill gate, especially G3. Meta also reviews for misleading claims, and a policy hit on a page hurts organic reach.
- Metric: **shares + DM-sends**. On Instagram, "Sends" is the strongest distribution signal for Reels. Optimize for it.
- Kill rule: 10–14 days.

## What changes

### CTA
There's no yellow TikTok Shop cart. Swap the SOP's CTA lines for one of these (pick ONE per video, per Copy Framework):
- **Comment keyword → auto-DM link** (e.g. "Comment BRUSH and I'll send you the link"). Best for IG: it also drives comments.
- **"Link in bio"** — lowest friction to set up, weakest conversion.
- **Facebook:** link in the first comment or the caption, or a tagged Facebook Shop product if the page has one.
Keep the SOP's scarcity + price beat. Only claim scarcity if it's real (Copy Framework §6.9).

### Captions matter more than on TikTok
Facebook especially: older audience, reads captions, clicks "See more." That's where the Copy Framework does most of its work.
- **Instagram caption:** first line = headline (only ~125 chars show before "more"). Short body, 3 bullets, one CTA, 3–5 niche hashtags.
- **Facebook caption:** longer is fine. Full Copy Framework build order: headline → problem → tease → reveal → bullets →
  proof → offer → CTA → P.S. Few or no hashtags.

### On-screen text = the headline
Most Reels are watched sound-off at first. The first text overlay is doing the headline's job (Copy Framework §3):
attention + audience + complete message + pull into the next beat. It must pass the Headline Test.

### Audience
FB/IG Reels skew older than TikTok (25–55+), with more homeowners, parents, and pet owners. Products for those buyers get
the full Organic Fit points in the rubric. Archetypes 6 (Danger Rescue), 7 (Crying Child), and 8 (Intervention) fit
that crowd well.

### Posting
- Post the same Reel to IG and FB (cross-post or native upload). Track each platform's results separately in `/results`.
- Trend-stack slot (Archetype 3): post within 48 hours of the moment, same as the SOP says.

> Tip: these are starting assumptions, not tested rules. Replace them with what your own `/results` data shows.
